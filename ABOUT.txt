1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Lake Side Academy Management System is a production-grade, executive-tier
educational administration platform engineered for real school operations.

The platform embodies the official crest of Lake Side Academy (an eagle clutching
a globe above an open book of wisdom, framed by bilingual English and Amharic
typography) and strictly implements authentic school data, zero placeholder mock tags,
and independent scroll viewports.

The platform provides dedicated, streamlined interfaces:

  • Admin Panel: Full executive institutional sovereignty, user & role permissions,
    academic curriculum setup, 5 sections (A-E) per grade with real-time student counts,
    grade enrollment distribution graph, teacher assignments, whole-school SMS broadcasts,
    tokenized result SMS generator, and comprehensive audit logs.
  • Directory / Records Office: Dedicated registrar records office interface.
    Generates unique 5-digit Student IDs (10001+), registers students with direct-typing
    Ethiopian Calendar date picker, automatic current Ethiopian date assignment,
    multi-child parent phone linking, debounced search, and comprehensive 7-tab dossiers.
  • Teacher Web: Clean, focused academic gradebook interface for faculty members.
    Strictly scoped to assigned classes, sections, and subjects. Provides spreadsheet-
    like mark entry, audited mark adjustment requiring mandatory justification,
    class rankings, and direct SMS communication with parents of assigned students.
  • Parent SMS Gateway: Parents receive real-time SMS notifications and academic
    result breakdowns directly from the live database without requiring app installations.
  • Ethiopian Calendar Engine: Native civil solar calendar conversion utility
    operating in Africa/Addis_Ababa timezone with automatic current Ethiopian date
    calculation and direct-typing DD/MM/YYYY date validation.

2. DESIGN & NAVIGATION ARCHITECTURE
--------------------------------------------------------------------------------
• No Top Navbar After Login:
  After login, the redundant top navbar is completely removed. The full-height
  sidebar (100vh) hosts the school branding, current Ethiopian date badge (2018 E.C.),
  global quick search (for authorized staff), navigation tabs, user profile badge,
  light/dark theme toggle, and sign out button.
• Dynamic Sections Architecture (A-C Baseline, Grade 5 A-B Only, Dynamic Add/Delete):
  - Removed default sections D and E across all classes.
  - Standard baseline features Sections A, B, and C.
  - Grade 5 Exception: Section C is removed; Grade 5 strictly has only Sections A and B.
  - Admin & Directory can dynamically add sections to any grade (e.g. adding Section D to Grade 8).
  - Empty sections (0 enrolled students) can be deleted dynamically with relational safeguards.
• Single Active Academic Year:
  The system automatically locks to the current active year (2018 E.C.), eliminating
  manual year creation clutter.
• Modern Minimalist SaaS Aesthetic:
  Pure white background (#FFFFFF) in light mode, sleek dark mode (#0B192C / #111827),
  zero emojis, refined typography (Outfit, Inter, Noto Sans Ethiopic), and subtle borders.


3. TECHNOLOGIES
--------------------------------------------------------------------------------
Backend:
  • Node.js v24.x (using native 'node:sqlite' DatabaseSync engine)
  • Express.js v4.21 (REST API, structured routing, error handling)
  • bcryptjs (Salted, secure one-way password hashing)
  • jsonwebtoken (JWT stateless authentication with bearer tokens)
  • SQLite 3 (WAL mode journal, PRAGMA foreign_keys = ON, transactions, indexed search)

Frontend:
  • React 18 & Vite 6 (Ultra-fast HMR and production build system)
  • Vanilla CSS Design System (Custom tokens, responsive grid, print media styles)
  • Lucide React (Crisp modern SVG iconography)
  • Custom Debounced Search Engine (Fast real-time filtering)

8. SECURITY & INTEGRITY SAFEGUARDS
--------------------------------------------------------------------------------
  • Password Security: Passwords hashed with bcryptjs (10 salt rounds).
  • SQL Injection Prevention: 100% parameterised queries through node:sqlite.
  • Scoped Access Control: Teachers can only view/grade students in their assigned
    classes. Unassigned classes return HTTP 403 Forbidden.
  • Immutability of Student IDs: Student IDs remain fixed 5-digit numbers throughout
    a student's entire tenure at Lake Side Academy.
  • Historical Record Preservation: Promoting a student creates a new active
    enrollment record while keeping past academic year assignments and marks intact.
  • Mandatory Reason Logging: Any adjustment to a student's mark requires an
    explanation and logs old and new scores with user identity and timestamp.
  • Parent Phone Deduplication: Prevents sending redundant duplicate broadcast
    messages when parents have multiple children in the targeted group.
  • Dual Class/Section Authority: Both Admin and Directory can create and maintain
    classes and sections.
